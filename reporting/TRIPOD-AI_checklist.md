| 6a                                                     | **Outcome definition**                           | VPC origin (RVOT/LVOT/intramural) established by electroanatomic mapping and ablation; reference standard set by blinded re-adjudication of all cases, independent of the model.                                                                                                                                                                                   | Methods 2.2; Results                                 |

| | **METHODS --- Analysis & model** | | |
| 10a                                                    | **Analytical / model type**                      | 1-D residual convolutional neural network with Squeeze-and-Excitation blocks and Instance Normalization; global average pooling feeds a fully connected classifier. A 12-dimensional MDI vector is fused at the pooling layer (268 features); its contribution was examined in a post hoc ablation (Supplementary Table S4).                                            | Methods 2.4; Figure 2                                |
| 10b                                                    | **Model development / tuning**                   | Label-smoothing cross-entropy, AdamW, CosineAnnealingWarmRestarts, Mixup; fixed 50 epochs with final-epoch weights and no checkpoint selection; external cohorts not used for development.                                                                                                                                                                         | Methods 2.4–2.5                                        |
| 10c                                                    | **Class imbalance**                              | Addressed via label smoothing, Mixup and augmentation; balanced accuracy and macro-F1 reported for the imbalanced three-class task.                                                                                                                                                                                                                                | Methods 2.4; Results                                 |
| 10d                                                    | **Model output & threshold**                     | Softmax probabilities; positive class RVOT; decision threshold 0.50; patient-level prediction by mean probability across recordings.                                                                                                                                                                                                                               | Methods 2.4; Results                                 |
| 11                                                     | **Model evaluation**                             | Patient-level stratified group five-fold cross-validation (no patient shared across folds); cluster (patient) bootstrap 95% CIs; accuracy, AUROC, AUPRC, sensitivity, specificity, PPV, NPV, balanced accuracy, macro-F1 and Brier score.                                                                                                                          | Methods 2.4–2.5; Results                               |
| 12                                                     | **Comparison / benchmarking**                    | Compared, as an exploratory analysis, against two blinded electrophysiologists who manually applied three established ECG algorithms (V2 transition ratio, V2S/V3R index, transition-zone index) on the same patients with a paired McNemar test (Supplementary Table S3); a gradient-boosted (XGBoost) baseline is reported descriptively (single held-out partition). | Methods 2.6; Supplementary Table S3                      |
